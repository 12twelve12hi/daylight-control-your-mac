# Third-party notices

Daylight Whiteboard Camera itself is licensed under the Apache License 2.0 (`LICENSE` at the project root, the standard text). This file lists what it bundles from others.

Daylight.app bundles two binaries it did not write, both inside `Contents/Resources/Vendor/`. `make fetch-tools` (`scripts/fetch-tools.sh`) downloads them with pinned versions and sha256 checks; neither binary is committed to this repository (only the license text is). The exact `ls -l`, `lipo -archs`, `file` and sha256 output of the copies that went into a build is in the `xcodebuild-logs` artifact of that CI run (`vendor.txt`).

The Apache License 2.0 text ships inside the app as `Vendor/LICENSE-Apache-2.0.txt` (committed as `LICENSES/Apache-2.0.txt`, scrcpy's copy with its copyright lines, copied by `make fetch-tools`; also at https://www.apache.org/licenses/LICENSE-2.0), as Apache-2.0 section 4(a) requires for a redistribution; this notices file is copied next to it as `Vendor/THIRD_PARTY_NOTICES.md`. The notice file shipped next to `adb` is the `platform-tools/NOTICE.txt` from the same zip; CI runs 37106402207 and 37109430893 confirmed it sits at that path (1,153,968 bytes). The bundled `adb` as measured by those runs: 19,993,936 bytes, `lipo -archs` prints `x86_64 arm64`, sha256 `9fdf861259dc807937b13afdd5f053c7fda9f3b7726933fe0e0f45130ecb8dc7`, `adb --version` prints `Android Debug Bridge version 1.0.41` and `Version 37.0.0-14910828` (LOOSE_ENDS B2).

The owner keeps the bundled `adb` as the default (LOOSE_ENDS A6, 2026-10-03). Legal note: redistributing Google's prebuilt `adb` falls under sections 3.4 and 3.5 of the Android SDK License, which deserve a legal read before the first public release; scrcpy and Homebrew ship the same binary. The two alternatives, downloading platform-tools on first use after the user accepts Google's terms and reusing an adb already installed on the Mac, are being built as Settings options (LOOSE_ENDS H1) so either can become the default without a redesign; building adb from AOSP in CI remains a further fallback.

Nothing else in the Mac app is third-party code: `DaylightKit`, the app and the camera extension are written in this repository on Apple's SDKs. The web whiteboard's build-time dependencies (Vite, TypeScript, Playwright) and the Android app's libraries (AndroidX graphics-core, OkHttp, kotlinx-coroutines) are declared in `web/package.json` and `android/app/build.gradle.kts` with their own licenses and are not redistributed by the Mac app except as the compiled web page and the Daylight Ink APK.
