# Anti-patterns: lessons other products paid for

What Daylight Whiteboard Camera should avoid, each with the product that paid for the lesson and the evidence. From the research swarm of 2026-10-04 (45 target reports, checked by verification agents). Companion pages: `IDEAS-FROM-OTHER-PROJECTS.md` and `REUSABLE-CODE.md`.

Writing rules: no em-dashes; LivePaper is a transflective LCD; the backlight is DC dimming; VRR is 45 to 90 Hz.

Evidence levels: **verified** means a verifier opened the source (code, developer documentation, or a fetched page) and it supports the row; **snippet** means most vendor sites were blocked by this environment's network policy and only consistent search-result text supports it. Snippet rows are kept because the lesson is plausible and useful, but treat them as leads, not facts. Where Daylight already avoids the trap, the last column says so, so the row becomes a regression guard rather than work.

## 1. The virtual camera and macOS

| Anti-pattern | Who paid | What happened | Evidence | Level | Lesson for Daylight |
|---|---|---|---|---|---|
| No way to remove the camera extension | OBS Studio | The macOS plugin only submits activation requests; users go looking for `systemextensionsctl` or recovery-mode workarounds | [OBS forum](https://obsproject.com/forum/threads/how-to-completely-remove-obs-virtual-camera.175824/); absence confirmed in [plugin-main.mm](https://github.com/obsproject/obs-studio/blob/master/plugins/mac-virtualcam/src/obs-plugin/plugin-main.mm) | snippet (code absence verified) | Keep "Uninstall camera" reachable from the menu (Daylight has deactivation) |
| Raw OS error text as the headline | OBS Studio | "An error has occured while installing the virtual camera: ... (OSSystemExtensionErrorDomain error 10.)"; the usual cause is a managed Mac | [OBS forum](https://obsproject.com/forum/threads/cant-start-virtual-camera-ossystemextensionerrordomain-error-10.185847); string in [en-US.ini](https://github.com/obsproject/obs-studio/blob/master/frontend/data/locale/en-US.ini) | snippet (string verified) | Plain text per error code (Daylight has it); add "Copy details for your IT admin" with the team id and extension bundle id |
| `fatalError` for packaging mistakes inside the extension | OBS Studio | A missing placeholder image or a failed `addStream` crashes the camera extension | [OBSCameraDeviceSource.swift](https://github.com/obsproject/obs-studio/blob/master/plugins/mac-virtualcam/src/camera-extension/OBSCameraDeviceSource.swift) | verified | Log a fault and degrade to the cream card (Daylight does) |
| The wrong counter decides when the sink stops | OBS Studio | `stopStreamingSink` tests the viewer counter instead of the sink state | [OBSCameraDeviceSource.swift](https://github.com/obsproject/obs-studio/blob/master/plugins/mac-virtualcam/src/camera-extension/OBSCameraDeviceSource.swift) | verified | Keep the `sinkStateAfterStop` tests (separate sink and viewer counters) |
| Deleting a shared system folder on update | OBS Studio (DAL era) | An admin `rm -rf '/Library/CoreMediaIO/Plug-Ins/DAL'` before copying its own plugin, taking other vendors' cameras with it | [plugin-main.mm](https://github.com/obsproject/obs-studio/blob/master/plugins/mac-virtualcam/src/obs-plugin/plugin-main.mm) | verified | Never delete outside our own bundle |
| Finding the sink stream by position | pyvirtualcam | "We'll just have to pray it's always at position 2 (index 1)." | [virtual_output.hpp](https://github.com/letmaik/pyvirtualcam/blob/main/pyvirtualcam/native_macos_obs_cmioextension/virtual_output.hpp) | verified | Select by stream direction (Daylight does) |
| Random noise when there is no source | akvirtualcamera | A `randomFrame` fallback is what callers see | [extensiondevicesource.mm](https://github.com/webcamoid/akvirtualcamera/blob/master/cmio/Extension/src/extensiondevicesource.mm) | verified | A calm card with one sentence (Daylight's cream placeholder) |
| Staying on the legacy DAL camera | Prezi Video | The camera vanished from Zoom after macOS Sonoma 14.1.1 until an app update | [Zoom community](https://community.zoom.com/t5/Zoom-App-Marketplace/Prezi-Video-Camera-option-now-not-available/td-p/154986) | snippet | Stay on CMIOExtension; test every macOS beta |
| Private display hooks broken by an OS update | Duet Display | macOS 10.13.4 stopped it working; users were told not to update until 10.14.2 | [TidBITS](https://tidbits.com/2018/04/08/macos-10-13-4-breaks-third-party-dual-display-systems/) | snippet | Public APIs only (CMIOExtension, AVFoundation, Network.framework) |
| Patching the meeting app so a camera loads | Camo (2020) | Removed Teams' code signature after an admin prompt so its DAL plugin would load | [Michael Tsai](https://mjtsai.com/blog/2020/08/03/camo-1-0/) | snippet | Never modify host apps; the signed extension already avoids it |
| Comparing the Darwin version with a macOS version | Streamlabs Desktop | `os.release()` major (24 on macOS 15) compared with `>= 15`, so macOS 11 to 14 users got the macOS 15 approval directions | [virtual-webcam.ts](https://github.com/streamlabs/desktop/blob/master/app/services/virtual-webcam.ts) | verified | Daylight uses `operatingSystemVersion.majorVersion` (ExtensionInstaller.swift); pin it with a unit test |
| Hard-coded System Settings pane names per OS | Rectangle | macOS 27 renamed the Accessibility pane path, breaking the deep link | [AccessibilityView.swift](https://github.com/rxhanson/Rectangle/blob/main/Rectangle/AccessibilityAuthorization/AccessibilityView.swift) | verified | Re-check every approval path and settings URL each macOS release |
| A permission window that quits the app on close | Rectangle | `exit(1)` on close plus an endless 0.3 s poll | [AccessibilityAuthorization.swift](https://github.com/rxhanson/Rectangle/blob/main/Rectangle/AccessibilityAuthorization/AccessibilityAuthorization.swift) | verified | "Welcome to Daylight" stays dismissible (it is) |
| Attributing camera use by scraping private logs | OverSight | A private `OSLogEventLiveStream`, three OS-specific message formats and a fixed 0.5 s wait | [LogMonitor.m](https://github.com/objective-see/OverSight/blob/master/Application/Application/LogMonitor.m) | verified | To name the app viewing Daylight Camera, use `CMIOExtensionClient` ([Apple](https://developer.apple.com/documentation/coremediaio/cmioextensionclient)) |
| Implicit gesture effects on by default | Apple Reactions | A thumbs-up sets off fireworks in meetings; users hunt for the toggle | [Acts of Volition](https://actsofvolition.com/2024/03/is-your-mac-making-mystery-thumbs-up-bubbles-on-video-calls/); default documented by [Apple](https://developer.apple.com/documentation/avfoundation/avcapturedevice/reactioneffectgesturesenabled) | snippet (API verified) | Keep the pen engage visibly reversible and predictable; warn once when Reactions are on, because they are baked into the webcam frames Daylight re-publishes |
| Not planning for macOS 15 Local Network privacy | Ecamm Live | Support articles on the local network prompt and "Stream Deck no longer controlling Ecamm after updating to Sequoia" | [Ecamm support](https://support.ecamm.com/en/articles/9977416-stream-deck-no-longer-controlling-ecamm-after-updating-to-sequoia); rules in [Apple TN3179](https://developer.apple.com/documentation/technotes/tn3179-understanding-local-network-privacy) | snippet (Apple verified) | Registering `_daylight-camera._tcp` needs the permission (TN3179); explain it before the prompt and detect a denial |
| Testing permission flows on ad hoc builds | Apple TN3179 | Local Network privilege is tracked by code signature and cannot be reset on macOS | [TN3179](https://developer.apple.com/documentation/technotes/tn3179-understanding-local-network-privacy) | verified | Test the prompt only on Developer ID builds, in a fresh user account or VM |

## 2. What the far end sees

| Anti-pattern | Who paid | What happened | Evidence | Level | Lesson for Daylight |
|---|---|---|---|---|---|
| Leaving the quality ceiling to help articles | Ecamm Live | A 1080p virtual camera, but Zoom sends less unless the HD setting and the plan allow it | [Ecamm support](https://support.ecamm.com/en/articles/9179741-ecamm-for-zoom-participant-video-resolution) | snippet | Say it in the product, at onboarding Finish |
| Board or face, never both | Teachers using a Wacom in Zoom | Teachers share the screen, so students lose the teacher's face | [Boston University](https://www.bu.edu/engit/teaching-remotely/using-a-wacom-tablet-with-zoom/) | snippet | Lead with "your face stays on screen"; it is the product's point |
| Overlays that only some clients render | Microsoft Teams (Presenter modes, PowerPoint Live annotations) | Web and mobile attendees see content and presenter separately and miss annotations | [Microsoft support](https://support.microsoft.com/en-us/teams/meetings/presenter-modes-in-microsoft-teams) | snippet | Keep compositing into one video stream so every client sees the same picture |
| Mirroring that flips unrelated text | Prezi Video for Zoom | Other text in the feed (shirts, virtual backgrounds) appeared mirrored | [Prezi FAQ](https://support.prezi.com/hc/en-us/articles/7543851436311-Prezi-Video-for-Zoom-App-FAQ) | snippet | Never mirror the board; never ask users to change their call app's mirroring; explain that their own preview may look mirrored |
| Content paths gated by edition or certified hardware | Google Meet (present from camera), Teams Rooms (content camera needs a Pro license) | Many users cannot reach the content-grade path | [Microsoft Learn](https://learn.microsoft.com/en-us/microsoftteams/rooms/content-camera) | verified (Teams), snippet (Meet) | Treat platform content paths as optional tips; the default camera path must stand alone |
| Gating picture quality behind payment | Vysor | "High Quality Mirroring" and "Go Wireless" are Pro; reviews report a capped bitrate and ads on the free tier | [koush/vysor.io](https://github.com/koush/vysor.io/blob/master/index.html) | verified (pricing), snippet (caps) | Never gate board legibility at the far end |

## 3. Ink and the board

| Anti-pattern | Who paid | What happened | Evidence | Level | Lesson for Daylight |
|---|---|---|---|---|---|
| An opaque compressed blob inside exported images | Excalidraw | The PNG-embedded scene is zlib JSON that only Excalidraw reads | [image.ts](https://github.com/excalidraw/excalidraw/blob/master/packages/excalidraw/data/image.ts) | verified | If we embed strokes in the PNG, embed the plain, versioned JSON so any tool can read it |
| A lossy derived format used as the source | Apple PencilKit | Points are "stored in a lossily compressed format" | [WWDC20 session 10148](https://developer.apple.com/videos/play/wwdc2020/10148/) | verified | The strokes JSON stays the source of truth; every render is derived |
| Destructive erase with no eraser stroke | Apple PencilKit | Erasing is an `erasingPath` operation; there is no eraser ink type to replay | [PKDrawing](https://developer.apple.com/tutorials/data/documentation/pencilkit/pkdrawing-swift.struct.json) | verified | Keep the eraser as recorded operations in Daylight's model |
| Sending predicted points | (Pointer Events specification) | Predicted events are valid only until the next real event | [Pointer Events](https://w3c.github.io/pointerevents/#predicted-events) | verified | Predicted ink is local wet ink only, never on the wire or in the saved JSON |
| Assuming an input API exists | tldraw | `getCoalescedEvents` disabled on iOS because it is sometimes absent | [useCanvasEvents.ts](https://github.com/tldraw/tldraw/blob/main/packages/editor/src/lib/hooks/useCanvasEvents.ts) | verified | Keep feature detection (Daylight's `web/src/caps.ts` does) |
| The best ink APIs gated to secure contexts | Chrome (Pointer Events, WebCodecs) | `getCoalescedEvents`, `pointerrawupdate` and all of WebCodecs are `[SecureContext]`; plain `http://` LAN pages lose them | [Pointer Events](https://w3c.github.io/pointerevents/#pointerevent-interface) | verified | Keep the USB `localhost` path and the plain-http hint (already done) |
| Pen strokes that turn into selection | Zoom Whiteboard | Strokes that start on an earlier stroke drag it instead of drawing | [Zoom community](https://community.zoom.com/t5/Zoom-Whiteboard/Problems-drawing-on-whiteboard-with-stylus/m-p/75198) | snippet | Never add a select gesture to the pen path |
| Format bloat | Microsoft ISF | Huffman, LZ, Gorilla, transform and metric tables, about 9,200 lines | [dotnet/wpf](https://github.com/dotnet/wpf/tree/main/src/Microsoft.DotNet.Wpf/src/PresentationCore/MS/internal/Ink/InkSerializedFormat) | verified | gzip first; never compress the LAN wire (about 2.6 KB/s) |
| A license key and watermark in an SDK | tldraw | Production use needs a key; the SDK enforces a watermark and may send usage data | [LICENSE.md](https://github.com/tldraw/tldraw/blob/main/LICENSE.md) | verified | Never let a third-party watermark path reach the camera feed; ideas only |
| Removing a clean presenter view people relied on | GoodNotes | Users asked to bring back presentation mode in GoodNotes 5 | [GoodNotes feedback](https://feedback.goodnotes.com/forums/191274-customer-suggestions-for-goodnotes/suggestions/36551317-bring-back-presentation-mode-in-goodnotes-5) | snippet | Keep the clean board identical across all three ink sources and versions |
| Gating annotation basics behind a plan | Loom | The drawing tool is only on Education, Business and Enterprise plans | [Loom support](https://support.atlassian.com/loom/docs/use-the-drawing-tool/) | snippet | Keep the pointer and the pen free |

## 4. Pairing, network and mirror

| Anti-pattern | Who paid | What happened | Evidence | Level | Lesson for Daylight |
|---|---|---|---|---|---|
| Raw adb output as the error UI | QtScrcpy, Escrcpy | Log text like "ip not find, connect to wifi?" and raw stderr shown to users | [QtScrcpy dialog.cpp](https://github.com/barry-ran/QtScrcpy/blob/master/QtScrcpy/ui/dialog.cpp) | verified | Translate every adb failure into a sentence plus an action (Daylight's failure rows 21 to 39) |
| Taking the first mDNS hit | Escrcpy | The scanner pairs with the first `adb-tls-pairing` service found | [scanner/index.js](https://github.com/viarotel-org/escrcpy/blob/main/desktop/electron/middleware/adb/helpers/scanner/index.js) | verified | Show the device name and confirm before pairing |
| Two adb copies fighting | Vysor users | "adb server version doesn't match this client", fixed by deleting tools and `adb kill-server` | [JanBask](https://www.janbasktraining.com/community/qa-testing/how-can-i-resolve-the-error-adb-server-version-doesnt-match-this-client) | snippet | Keep the private-port policy (`AdbServerPolicy.swift`); never kill the owner's adb |
| Recurring black screen without a diagnosis | Vysor | Needed a WebAssembly decoder and an H.264 profile detector to cure black screens | [vysor.io README](https://github.com/koush/vysor.io/blob/master/README.md) | verified | Keep "connected but no picture" as named states (Daylight rows 26, 27, 35, 36) |
| Letting TCP backpressure block the encoder | scrcpy | The encoder loop blocks on the socket write; fine on USB, bad on Wi-Fi | [SurfaceEncoder.java](https://github.com/Genymobile/scrcpy/blob/master/server/src/main/java/com/genymobile/scrcpy/video/SurfaceEncoder.java) | verified | Keep drop-until-key-frame on the Wi-Fi mirror |
| Discovery that cannot tell "blocked" from "nobody there" | LocalSend | The protocol had to add an HTTP legacy scan "when multicast was unsuccessful" | [localsend/protocol](https://github.com/localsend/protocol/blob/main/README.md) | verified | Always show a concrete state and the typed-address field (rows 18 and 30) |
| A fixed /24 subnet scan | LocalSend | `scan_subnet` walks 0 to 255 of the first three octets and misses larger subnets | [discovery/mod.rs](https://github.com/localsend/localsend/blob/main/packages/core/src/discovery/mod.rs) | verified | Derive the range from the netmask and cap it |
| Expecting LAN discovery on isolated Wi-Fi | Chromecast | Guest, hotel and public networks with client isolation cannot set up a Chromecast | [Google support](https://support.google.com/chromecast/answer/3294846) | snippet | Stop retrying and point to USB or Tailscale (row 18 does) |
| A blanket "no VPN" rule | Supernote | Help text forbids a proxy or VPN for mirroring | [Supernote help](https://ratta.helpjuice.com/1791924-screen-mirroring) | snippet | Keep Tailscale as a supported path |
| A wide fixed port range, or two ports for one feature | KDE Connect, Weylus | KDE: UDP 1716 plus TCP 1716 to 1764; Weylus: "open both 1701 and 9001" | [lanlinkprovider.cpp](https://github.com/KDE/kdeconnect-kde/blob/master/core/backends/lan/lanlinkprovider.cpp), [Weylus Readme](https://raw.githubusercontent.com/H-M-H/Weylus/master/Readme.md) | verified | Keep 7788 as the one port and name it in the troubleshooter |
| A hidden radio side channel for discovery | Quick Share (NearDrop) | Android only advertises after a BLE beacon that macOS cannot send | [NearDrop PROTOCOL.md](https://github.com/grishka/NearDrop/blob/master/PROTOCOL.md) | verified | Stay on plain mDNS, the typed URL and USB |
| A short PIN treated as a secret | UKEY2 design, NearDrop | A 4-digit fold is about 13 bits and safe only with commit-then-reveal | [google/ukey2](https://github.com/google/ukey2/blob/master/README.md) | verified | A short code on both screens is a confirmation, never a password |
| Speed bought with no authentication | rmview (VNC), reStream, Supernote mirror | Servers on all interfaces with no authentication or encryption | [reStream README](https://github.com/rien/reStream/blob/main/README.md) | verified | Keep the Allow prompt on every path, the fast ones included |
| Shipped default credentials and a bundled certificate | goMarkableStream | `admin` / `password` and `assets/cert.pem` in the repository | [goMarkableStream README](https://github.com/owulveryck/goMarkableStream/blob/main/README.md) | verified | No shared secrets in builds |
| Coupling to reverse-engineered firmware internals | rmview, goMarkableStream | Separate backends below 2.8 and from 2.9; re-download after each system update | [rmview README](https://github.com/bordaigorl/rmview/blob/vnc/README.md) | verified | MediaProjection and MediaCodec only; any SolOS internal behind a version check |
| Developer-grade setup | reStream | ed25519 keys unsupported; RSA must be re-enabled by hand | [reStream README](https://github.com/rien/reStream/blob/main/README.md) | verified | USB debugging setup is one guided step with a fix per error |
| A vendor SDK over plain HTTP plus a hidden-API bypass | Boox pen SDK, Notable | `http://repo.boox.com` and `hiddenapibypass` required | [Notable build.gradle](https://github.com/olup/notable/blob/main/app/build.gradle) | verified | Keep any future SolOS fast-ink service behind Daylight's own interface |
| Vague, cause-free errors with hidden prerequisites | Apple Sidecar | "The device timed out"; users discover the Apple ID, hotspot and Handoff requirements only after failing | [iBoysoft](https://iboysoft.com/tips/sidecar-not-working.html) | snippet | Keep the layer-named failure matrix |
| A custom UDP input protocol | Moonlight and Sunshine | Pen packets are "a protocol extension only supported with Sunshine", plus ENet plumbing on both ends | [InputStream.c](https://github.com/moonlight-stream/moonlight-common-c/blob/master/src/InputStream.c) | verified | Measure TCP stalls before building a second transport |

## 5. Business and product shape

| Anti-pattern | Who paid | What happened | Evidence | Level | Lesson for Daylight |
|---|---|---|---|---|---|
| Requiring the far end to install your app | Around | Adoption depended on everyone switching; it shut down on March 31, 2025 after the Miro acquisition | [AlternativeTo](https://alternativeto.net/news/2025/1/the-video-call-app-around-is-shutting-down-just-over-a-year-after-its-acquisition-by-miro) | snippet | Stay a camera inside the call apps people already use |
| Requiring a far-end add-on | FigJam | In-call use needs Figma for Zoom or the Meet add-on | [Figma help](https://figma-signup.helpjuice.com/meetings/figma-and-zoom) | snippet | Zero far-end setup is the differentiator; add no far-end requirements |
| Tying users' boards to a cloud service | Google Jamboard | View-only on October 1, 2024; files deleted after December 31, 2024 | [Google support](https://support.google.com/jamboard/answer/14084927) | snippet | Boards stay local, exportable files |
| A free tier that silently turns work read-only | Miro | Only the 3 most recent boards stay editable; users blocked from a 4th | [Miro community](https://community.miro.com/ask-the-community-45/free-plan-won-t-let-me-create-a-4th-board-i-thought-boards-were-unlimited-28959) | snippet | If "Send to Miro" ships, reuse one board and explain the limit in plain words |
| Forcing everyone into the presenter's view | Miro (FigJam softens it) | Miro shows every participant a join or decline modal; FigJam gives viewers a few seconds to ignore Spotlight | [Figma help](https://figma-signup.helpjuice.com/facilitate-meetings-with-spotlight) | snippet | The far end cannot decline our camera, so the engage must stay gentle and predictable |
| The best path needs paid hardware | Astropad Luna Display | A dongle sold as "Second Display Hardware" | [Astropad shop](https://shop.astropad.com/products/luna-display) | snippet | Stay zero-hardware on the Mac |
| Using the upstream project's name | Streamlabs | "Streamlabs OBS" renamed "Streamlabs Desktop" in November 2021 after the OBS Project objected | [The Register](https://www.theregister.com/2021/11/18/streamlabs_drops_obs/) | snippet | Credit the OBS sink-stream pattern (SPEC D33); never use "OBS" in a name |
| An auto-tune built on someone else's API | Streamlabs Desktop | The optimizer and its onboarding step are disabled ("temporarily disable auto config until migrate to new api") | [auto-config/index.ts](https://github.com/streamlabs/desktop/blob/master/app/services/auto-config/index.ts) | verified | Own any probe, keep it to seconds, and end in safe defaults |
| Silently ignoring a control | Streamlabs Desktop | The selective-recording toggle returns early while live, with no feedback | [streaming.ts](https://github.com/streamlabs/desktop/blob/master/app/services/streaming/streaming.ts) | verified | Disable a control with a stated reason |
| Hotkey simulation as an API | OBS WebSocket (its own warning) | "In 9/10 usages of hotkey requests, there exists a better, more reliable method" | [protocol.md](https://github.com/obsproject/obs-websocket/blob/master/docs/generated/protocol.md) | verified | Expose semantic actions (keep, clear, layout), never "press the chord" |
